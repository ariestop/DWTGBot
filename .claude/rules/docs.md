# Документация

`docs/` — источник истины, индекс — `docs/README.md`. Порядок старшинства:
ADR → тематические документы → комментарии в коде → корневой README.

- **Новое и изменяемое — на русском.** Идентификаторы, команды, env, пути,
  маршруты, имена событий и библиотек не переводить. Существующий
  английский текст переводится только вместе с содержательной правкой.
- Поведение изменилось → документ меняется в том же PR (таблица
  «Quick lookup by task» в `docs/README.md`).
- Пути к файлам — от корня репозитория, без номеров строк. Пути и события
  в обратных кавычках должны существовать: `app/tests/test_docs_references.py`
  (заготовки вида `<platform>` и `NNNN` допустимы).
- Команды для прода пишите под `single` и journald; `docker compose logs`
  перед `jq` — с `--no-log-prefix`.
- Диаграммы — Mermaid. Таблицы лучше прозы. Статус в шапке:
  `Status: Stable | Evolving | Draft`.
- Новый документ верхнего уровня — только если не подходит ни один
  существующий.
- Зафиксированное решение меняется новым ADR (`docs/adr/NNNN-<slug>.md`:
  Context / Decision / Consequences / Alternatives), строка в индексе
  `docs/adr/README.md`. Принятые ADR не переписывают: дополнение —
  блоком «Дополнено (дата)», замена — новым ADR.
- CHANGELOG: запись в начало `[Unreleased]`; работа на сервере — блок
  **Действия оператора**.
